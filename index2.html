🔑 Anthropic API Key

Für die Code-Analyse wird die Claude API benötigt.
Den Key findest du unter console.anthropic.com.
Er wird nur lokal gespeichert (localStorage) – unverschlüsselt und zeitlich unbegrenzt. Jede Browser-Extension mit Seitenzugriff kann ihn auslesen.

Empfehlung: eigenen Key mit Spending-Limit nutzen (console.anthropic.com → Limits) statt des Haupt-Keys.

🗑 Code löschen?

Der gesamte Inhalt des Editors wird gelöscht. Dies kann nicht rückgängig gemacht werden.
